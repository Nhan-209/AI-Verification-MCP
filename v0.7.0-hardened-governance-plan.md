# 🛡️ Architectural Roadmap: v0.7.0 Hardened AI Governance & Evidence Verifier

## 1. Executive Summary & Problem Analysis

Based on the deep code review of the `main` branch of `Nhan-209/AI-Verification-MCP`, this document specifies the architectural transition from a **heuristic quality signal checker** to a **production-grade deterministic Evidence & Policy Enforcement Layer**.

### Core Vulnerabilities & Architectural Gaps Identified

| # | Vulnerability / Flaw | Component | Impact | Target Fix |
|---|---|---|---|---|
| 1 | **URL Host Spoofing** | `ResearchGate` | High | Substring `contains("github.com")` allows `github.com.attacker.com` to pass as authoritative. Parse hostname boundaries strictly. |
| 2 | **Nonexistent File = Verified** | `ResearchGate` | Critical | `else` branch in local file check marks nonexistent files as verified. Nonexistent files must be marked unverified. |
| 3 | **Code Block Citation Loophole** | `ResearchGate` | High | Presence of ```` ``` ```` awards `verified += 1` to technical claims. Remove code blocks as factual claim proof. |
| 4 | **Exploratory Action Spoofing** | `PlanDag` | High | Substring `contains("test")` allows `exfiltrate_test_data` to bypass plan DAG. Add destructive prefix blocklist and word boundary tokens. |
| 5 | **DAG State Contamination** | `PlanDag::record_step` | Medium | `self.execution_log.push()` occurs before validation. On `Err`, state is contaminated. Enforce transactional commit on success only. |
| 6 | **Deep Mode Coverage Inconsistency** | `UnifiedAudit` | Medium | README promised Critical for incomplete coverage in deep mode, but code used Warning. Enforce Critical in deep mode. |
| 7 | **Foresight Negation Blindspot** | `ForesightEngine` | Medium | `"no timeout, no retry"` scores 100% defensive coverage. Add negation prefix parsing (`"no "`, `"without "`). |

| 9 | **Renormalization Score Gaming** | `UnifiedAudit` | High | Omitting code/plan/research allows high confidence text to score 95% and receive `ALLOW`. Enforce evidence requirements and hard policy invariants. |
| 10 | **RFC Registry Grounding** | `ResearchGate` | Medium | Numeric range 1..9999 overclaims. Distinguish well-known published RFC standards from unrecognized numbers. |
| 11 | **Adversarial Benchmark Expansion** | `tests/adversarial_suite` | High | Expand suite with 15 adversarial attack vectors (domain spoofing, negation traps, DAG rollback, score gaming). |

## 3. Detailed Technical Architecture

### 3.1 Strict URL Hostname Boundary Matching
```rust
pub fn is_authoritative_host(raw_url: &str) -> bool {
    let clean = raw_url.trim().to_lowercase();
    let without_proto = if let Some(stripped) = clean.strip_prefix("https://") {
        stripped
    } else if let Some(stripped) = clean.strip_prefix("http://") {
        stripped
    } else {
        return false;
    };
    
    let host = without_proto
        .split(['/', '?', '#', ':'])
        .next()
        .unwrap_or("")
        .trim();
        
    if host.is_empty() {
        return false;
    }

    AUTHORITATIVE_DOMAINS.iter().any(|&domain| {
        host == domain || host.ends_with(&format!(".{}", domain))
    })
}
```

### 3.2 Transactional DAG State
```rust
pub fn record_step(&mut self, task_id: &str) -> Result<String, String> {
    // 1. Validate dependencies first
    if let Some(task) = self.tasks.get(task_id) {
        for dep_id in &task.dependencies {
            if let Some(dep_task) = self.tasks.get(dep_id) {
                if dep_task.status != TaskStatus::Completed {
                    return Err(format!("Dependency violation: Task '{}' before '{}'", task_id, dep_id));
                }
            }
        }
    } else if !Self::is_exploratory_action(task_id) {
        return Err(format!("Scope creep violation: Task '{}' not in plan DAG", task_id));
    }

    // 2. Commit transaction ONLY on success
    self.execution_log.push(task_id.to_string());
    if let Some(task) = self.tasks.get_mut(task_id) {
        task.status = TaskStatus::Completed;
    }
    Ok(format!("Task '{}' committed successfully", task_id))
}
```

### 3.3 Anti-Spoofing Exploratory Actions
```rust
pub fn is_exploratory_action(action_id: &str) -> bool {
    let lower = action_id.to_lowercase();
    
    // Mutation or destructive verbs immediately disqualify
    const MUTATION_VERBS: &[&str] = &[
        "implement", "create", "build", "add", "modify", "delete", "remove",
        "drop", "exfiltrate", "write", "steal", "leak", "curl", "wget", "exec",
        "xóa", "tạo", "sửa", "thêm", "chạy"
    ];
    let tokens: Vec<&str> = lower.split(|c: char| c == '_' || c == '-' || c == ' ' || c == '.').collect();
    if tokens.iter().any(|&t| MUTATION_VERBS.contains(&t)) {
        return false;
    }

    const EXPLORATORY_VERBS: &[&str] = &[
        "read", "view", "check", "inspect", "grep", "search", "list",
        "find", "stat", "status", "test", "audit", "verify", "diff",
        "khảo sát", "đọc", "kiểm tra", "tìm", "tra cứu"
    ];
    tokens.iter().any(|&t| EXPLORATORY_VERBS.contains(&t))
}
```

### 3.4 Foresight Negation Detection
```rust
fn is_negated_term(lower_text: &str, term: &str) -> bool {
    const NEGATION_PREFIXES: &[&str] = &[
        "no ", "not ", "without ", "lack of ", "never ", "don't ", "do not ",
        "cannot ", "không có ", "chưa có ", "thiếu "
    ];
    for &neg in NEGATION_PREFIXES {
        let pattern = format!("{}{}", neg, term);
        if lower_text.contains(&pattern) {
            return true;
        }
    }
    false
}
```
